### Optimal Publishing Days

**Rationale**: Based on engagement data, these days/times yield highest open rates and click-through rates for target audience.

- **Minimum**: 1 post per week
- **Maximum**: 4 posts per week (avoid content fatigue)

## Pre-Publication Checklist

Before adding a post to this queue, ensure:

- [ ] Post has been reviewed and approved (passed Workflow_Instructions.md checklist)
- [ ] File has been moved from Drafts_For_Review/ to Approved/
- [ ] Target persona is clearly identified
- [ ] Category and tags are selected
- [ ] Publish date/time is scheduled
- [ ] Featured image is prepared (1200x630px)
- [ ] Meta description is written (150-160 characters)
- [ ] Internal links are identified (2-3 to service/guide pages)

---

## Post-Publication Tasks

After publishing, complete:

- [ ] Verify post is live and displays correctly
- [ ] Test all links (internal and external)
- [ ] Check mobile display
- [ ] Share on social media channels
- [ ] Add to email newsletter (if applicable)
- [ ] Monitor analytics for first 48 hours
- [ ] Update this file with "Published" status and URL
